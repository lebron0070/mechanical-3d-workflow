# 默认界面与操作分区

此布局是本 skill 的网页默认合同，源于用户认可的大黄蜂实验室布局。实现不依赖大黄蜂工程或素材。用户指定别的布局时允许覆盖；否则保留分区和操作位置，以便更换机械对象后仍能直接上手。

## 桌面骨架

```text
┌ 项目标识 / 名称 ── 形态选择（有多形态时） ── 源模型下载 ┐
│                                      │ 动作控制台      │
│             三维舞台                 │ 当前模式 / 状态 │
│ 左上标题                  右下视角组 │ 动作选择        │
│                           全局重置   │ 速度 / 关节参数 │
│ 底部状态 / 操作提示 / 模型统计        │ 可选声音与录制  │
├──────────────────────────────────────┤ 当前组件        │
│ 变形时间轴（只有真实多形态时显示）    │ 名称 / 作用     │
│ 拆解百分比 / 还原装配 / 主要结构动作 │ 选择 / 聚焦     │
│                                      │ 返回整体 / 说明 │
└ 项目类型 / 演示边界 / 本地状态 ─────────────────────────┘
```

- 顶栏约 64–76px，侧栏约 288–350px；舞台占剩余空间，不挤成配图。以上是起点而非必须逐像素一致。
- 基础视觉为柔白背景、白色面板、细灰边线、克制圆角、单一对象相关强调色；动作选中使用浅色底，主要结构动作使用深色实底。维持同一字号层级、控件密度和留白，不把控制项改成营销大卡片。
- 舞台、底部控制条和侧栏是独立布局区域，控制面板不得覆盖模型。舞台标题和小型镜头工具可叠放在安全边缘。

## 区域职责

| 区域 | 放什么 | 不放什么 |
|---|---|---|
| 顶部 | 项目标识、名称、形态端点选择、源模型下载 | 行走、关节、部件说明 |
| 舞台 | 模型、标题、加载/失败反馈、主视角、正面或俯视、全局重置、状态 | 大面积参数表单 |
| 底部结构控制 | 拆解滑条 0–100%、还原装配；多形态时增加时间轴、播放暂停、倍率、反向变形 | 步频、发动机转速、机械臂关节 |
| 右侧动作 | 模式状态、互斥动作按钮、运行速度、对象相关关节；用户要求时加入声音/录制 | 虚构动作、与对象无关的固定按钮 |
| 右侧部件 | 当前总成名称、功能、选择器、聚焦、返回整体、说明与资产入口 | 将每个紧固件默认作为顶层可选项 |
| 页脚 | 原创/来源性质、概念或仿真边界、本地状态 | 无依据的工业认证 |

## 稳定交互合同

1. 拆解滑条连续控制总成外移，显示目标百分比；一键拆解到 100%，还原装配回 0%。还原装配不暗中重置运行速度或停止动作。总成不缩小。
2. 动作按钮显示当前状态。停止/待机、动画暂停、还原装配、全局重置语义分开：待机回站立或静止姿态；暂停冻结需要暂停的动画；还原只改拆解；全局重置恢复初始动作、速度、拆解、选择和视角。
3. 点选及下拉选择指向同一总成状态；选中后高亮，其他组件线框或淡化。聚焦按实际包围盒取景；返回整体恢复材质与整体相机。
4. 镜头可手动接管。加载前禁用依赖模型的控件；失败反馈可见。系统减少动态效果时停止连续动画，但仍能手动改变拆解进度、选择和聚焦。
5. 只有一个形态时顶栏使用静态模式标签或省略切换；不添加假变形时间轴。没有声音、录制、特技需求时不显示对应按钮或占位区域。
6. 机构运行与拆解状态独立：拆开仍运行时标明演示含义。时间轴用于结构变化，不冒充运动速度控件。

## 跨对象映射

- 机械蜘蛛：动作区为待机/行走、步频；底部为总成拆解与还原。
- 发动机：动作区为启动/停止、演示转速；底部为总成拆解与还原。
- 机械臂：动作区为各轴参数、夹爪、归位；底部为总成拆解与还原。
- 变形机器人：顶栏选择形态；底部增加变形时间轴和反向；侧栏随形态显示适用动作。

## 窄屏与验收

窄屏依次排列：顶栏→舞台→结构控制→动作和部件控制台→页脚。舞台保留足够独立高度，控制条不悬浮遮挡足端，侧栏可自然下滚。禁止横向溢出。展开态和聚焦态重新按视口取景。

交付前验证：桌面分区位置、窄屏顺序、滑条中间值及 0/100 端点、拆解时运行、还原不影响动作、待机、全局重置、选中/聚焦/返回、减少动态效果及加载失败。对照截图确认遵循布局，不能只用 DOM 或文字匹配代替视觉验收。
