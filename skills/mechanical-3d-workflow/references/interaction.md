# 机构、拆解和变形

## 原理演示先建立驱动关系

区分驱动输入、固定件、被驱动件和关系式。用一个连续相位控制关联机构，不能给每个零件随意加独立正弦。使用 `phase += dt * omega`，变速时不重置相位。

- 转子：角速度单位明确；`omega = rpm * 2π / 60`。演示转速可降速以免视觉混叠，UI注明非实时比例。
- 外啮合齿轮：角速度比为负的齿数反比；内啮合、行星机构需单独推导，不能沿用同一个公式。
- 曲柄滑块：在无偏置且连杆长L大于曲柄半径r时，轴线上位置可用 `x = r*cos(theta) + sqrt(L²-r²*sin(theta)²)`；检查定义的原点、死点和连杆朝向，不把该式用于偏置机构。
- 机械臂：由实际关节轴/支点与父子关系做正向运动学。IK只有用户需要目标点控制时加入，并检查可达性和关节限位。
- 步行机械体：先定义前进方向、支撑接触和足端目标，再求关节。原地跟随展示的地面与支撑足相对身体后移；真实世界前进时支撑足应锁在世界地面。

按型号核对发动机转子/定子、轴系和级间关系；燃烧、气流粒子是示意，不等于CFD。资料不足时只展示已确认机制或明确标注假设。

## 拆开仍运转

展示父节点应用装配/爆炸偏移，子节点在局部坐标运转。例如 `world = product * explodedAssembly * localJoint * mesh`；有多层关节时递归组合。每帧从基础姿态求解，避免累积偏移。

拆解距离按包围盒和邻件间距确定，中心组件显式指定外移方向。总成大小保持不变。相互连接的轴/管路拆开后若断开，可保持同步原理动画，但不能伪称仍为真实完整传动。

## 选择、聚焦和说明

raycast命中网格/实例后映射到总成ID；选中整组高亮。按总成世界包围盒移动相机；其他组件按需求淡化或用边线显示，保留空间关系。临时材质不要污染共享材质实例，退出恢复颜色、透明度、深度设置和可见性。

说明至少包含名称、作用、与相邻总成的关系和当前运行状态。未知型号数据不填造数值。优先保证展开态可点选，不能靠不断缩小场景解决拥挤。

## 多形态路径（仅在要求时）

用命名姿态A/B及确定的转换边，而不是全局固定“人/车”。要求共用部件时不得用两个整体模型显隐替代。局部姿态示意：

```text
u = clamp((t - delay) / (1 - delay), 0, 1)
e = u*u*(3-2*u)
p = lerp(pA,pB,e) + arc * sin(π*u)^1.25
q = slerp(qA,qB,e) * axisAngle(axis,2π*integerTurns*e)
```

约束 `0<=delay<1`，轴非零并归一化，四元数归一化；这里旋转按局部轴后乘。t为0/1时直接返回存储端点。反向让同一个t递减，相同t必须得到同一姿态。多于两种形态按转换边分别验证，不假设任意两种端点可无碰撞切换。

## 状态和镜头

将运行、速度、拆解量、选择、转换进度、播放状态与重置集中管理。运行和拆解是否共存按需求决定，不默认互锁。转换需要收束原动作时设准备阶段，暂停也冻结准备阶段。

以实际边界取景：球半径r、水平/垂直半视角中的较小值α，距离至少 `r/sin(α)` 再加留白。重新计算展开、转换途中和聚焦的范围；竖屏不能沿用横屏固定距离。自动镜头允许手动接管；减少动态效果时提供静态进度查看。
